# NLSM_2D

Numerical tools for simulations and analysis of the two-dimensional O(3) non-linear sigma model. 

This repository includes reference implementations developed during my Ph.D. research, contains: 

## Generation of field configurations and basic operators 

-- Wolff-cluster algorithm.
-- Extraction of one-particle modes.
-- Extraction of the O(3) isospin current modes. 

## Euclidean correlators

-- One-particle self correlators
-- Two-particle correlators
-- One-particle 3-point correlators
-- Two-particle 3-point correlators using optimized interpolators

## Correlator analysis 

-- Simple fits of one-particle self correlators
-- Variational analysis of the two-particle correlation matrix
-- Extraction of one-particle matrix elements
-- Extraction of two-particle matrix elements

## Reconstruction of Scattering observables 

-- Analysis of the two-particle scattering matrix using L\"uscher's quantization condition
-- Parameterization of the two-particle scattering amplitude
-- Parameterization of the one-particle O(3) isospin form factor
